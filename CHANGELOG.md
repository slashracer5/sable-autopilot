# Changelog

## 1.5.3 (2026-11-17) - first public release
General multirotor autopilot `ap`: wizard-based setup for any multirotor or lean-only (tandem) ship, simulator, hover / route / transit flight, tuning, diagnostics and crash recovery, all running inside ComputerCraft. See `docs/DESIGN.md` for the full development history and measurements.
- Verified on real ships: tricopter, quadcopter and a tandem helicopter (hover to a few cm; 14.9 km transit at a peak of 142.9 m/s on the helicopter).
- 256 built-in selftest checks (`ap selftest`).
